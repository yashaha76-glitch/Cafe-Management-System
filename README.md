# Cafe Management System ☕ 

A desktop-based Cafe Management System developed as a university project using C# Windows Forms and MySQL. The system helps in managing cafe items, customer orders, billing, and maintaining records efficiently.

## Technologies Used
- C#
- Windows Forms
- MySQL 8.0
- MySQL Workbench 8.0
- Visual Studio 2022
- .NET Framework

## Features
- User Login System for secure access 
- Add, Update, and Delete Cafe Items 
- Customer Order Management 
- Automatic Bill and Invoice Generation 
- Search and Update Records 
- Database Storage and Management 
- Easy and User-Friendly Interface 
- Fast and Accurate Calculations 
- Secure Record Maintenance

## How to Run
1. Download or clone the repository.
2. Open `Cafe Project.sln` in Visual Studio 2022.
3. Import the SQL database into MySQL.
4. Configure your local database connection.
5. Build and run the project.
